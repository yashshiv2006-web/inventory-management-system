Retail Optimization Mathematical Model

This module uses an educational moving average sales velocity model with safety stock buffers:

Daily Run Rate = Total Sold ÷ 30 Days
30-Day Demand = Daily Run Rate × 30
Reorder Quantity = Max(0, (Demand + Safety Stock) - Current Stock)
